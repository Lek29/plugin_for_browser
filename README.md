# Фильтр желтушных новостей

Проект представляет собой асинхронный веб-сервер, который анализирует статьи с новостных сайтов (сейчас поддерживается [ИНОСМИ.РУ](https://inosmi.ru/)). Сервер скачивает текст статьи, оценивает уровень «заряженности» текста негативными словами и возвращает результат в формате JSON.



### Как это работает:
1. **Клиент** отправляет GET-запрос с набором ссылок.
2. **Сервер** параллельно (асинхронно) скачивает содержимое каждой статьи.
3. **Адаптер** очищает HTML, оставляя только чистый текст заголовка и статьи.
4. **Анализатор** разбивает текст на слова, приводит их к начальной форме (лемматизация) и сравнивает со словарем «заряженных» слов.
5. **Результат** выдается в виде рейтинга (score) от 0 до 1.

## Как установить

Вам понадобится Python версии 3.11 или старше.

1. **Создайте виртуальное окружение и активируйте его:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Linux/macOS

   .venv\Scripts\activate     # Для Windows
2. **Установите зависимости:**

    ```bash
    pip install -r requirements.txt
    ```
---
## Подготовка окружения
Создайте файл `.env` в корневой папке и настройте параметры (или скопируйте пример ниже):

```env
# Настройки Redis
REDIS_HOST=redis_db
REDIS_PASSWORD=change_this_to_secure_password
REDIS_PORT=6379

# Настройки приложения
APP_EXTERNAL_PORT=8080
```
---
## Как запустить
Запустите сервер командой:

```bash
python server.py
```
Сервер будет доступен по адресу: `http://localhost:8080`

## Запуск с docker-compose

```bash
  docker-compose up --build
```

## Использование API
Эндпоинт: `GET /analyse?urls=...`

**Пример запроса:**

`http://localhost:8080/analyse?urls=https://inosmi.ru/politic/20190629/245376799.html`

**Пример ответа:**

```json
[
  {
    "status": "OK",
    "url": "[https://inosmi.ru/politic/20190629/245376799.html](https://inosmi.ru/politic/20190629/245376799.html)",
    "score": 0.39,
    "words_count": 5452
  }
]
```

---
## Защита и ограничения
Сервер имеет встроенную защиту от перегрузок:

- **Ограничение количества ссылок:** не более 10 URL за один запрос. При превышении возвращается ошибка `400 Bad Request`.

- **Таймауты:** если сайт не отвечает в течение нескольких секунд, обработка прерывается со статусом `TIMEOUT`.

## Как запустить тесты
Для проверки надежности кода используются автотесты на базе `pytest`.

Запуск всех тестов (включая тесты сервера, инструментов обработки текста и адаптеров):

```bash
  python -m pytest
```
Отдельные тесты для модулей:

- `python -m pytest test_server.py` — проверка логики сервера и таймаутов.

- `python -m pytest text_tools.py` — проверка анализа текста.

- `python -m pytest adapters/inosmi_ru.py` — проверка работы парсера ИНОСМИ.
